STUDENT DUMP — объединённая версия

Что объединено:
- Сохранены backend, Docker Compose, API, модели, миграции и страницы материалов/загрузки/форума из переданного архива.
- Сохранены маршруты /, /m/:id, /upload, /forum, /forum/new и /forum/:id.
- Обновлены frontend/src/App.tsx и frontend/src/pages/SearchPage.tsx: добавлены навигация и главная страница в тёмном авиационном стиле STUDENT DUMP.
- Обновлён frontend/src/index.css: добавлена визуальная система и тёмное оформление существующих страниц.
- Добавлено frontend/public/su57-hero.png — новое изображение самолёта с гербом МАИ.

Запуск:
1. Распаковать архив.
2. В корне проекта создать .env на основе .env.example (если ещё не создан).
3. Запустить Docker Desktop.
4. В терминале из корня проекта выполнить: docker compose up --build
5. Открыть http://localhost:5173/

Примечание:
Исходные backend-файлы и API-реализация из архива товарища не переписывались.
Проверка npm build в этой среде не завершилась: установка npm-зависимостей превысила лимит времени.
